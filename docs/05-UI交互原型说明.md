## 一、原型范围

本原型覆盖 Phase 0 MVP 核心页面，支持完整点击流转（Mock 数据，无真实后端）。

| 模块 | 页面 | 路径 |
|------|------|------|
| 欢迎 | 品牌介绍 + 注册/登录入口 | `/welcome` |
| 认证 | 登录（含福利弹窗） | `/login` |
| 认证 | 注册（含云空间赠送弹窗） | `/register` |
| 引导 | 用户类型选择 | `/onboarding/user-type` |
| 引导 | 3 步新手引导 | `/onboarding/guide` |
| 首页 | 今日推荐 + 衣橱概览 + 提醒 | `/(tabs)` |
| 衣橱 | 列表 + 搜索 + 分类筛选 | `/(tabs)/wardrobe` |
| 录入 | 拍照/手动录入衣物 | `/(tabs)/add` |
| 记录 | 穿搭日历 + 统计 | `/(tabs)/records` |
| 我的 | 个人中心 + 子模块入口 | `/(tabs)/profile` |
| 云空间 | 用量统计 + 扩容方案 | `/profile/cloud-storage` |
| 会员 | 积分 + 权益 + 兑换 | `/profile/membership` |
| 订单 | 列表筛选 + 详情 + 取消 | `/profile/orders` |
| 反馈 | 类型 + 内容 + 截图提交 | `/profile/feedback` |
| 设置 | 通知 / 隐私 / 主题开关 | `/profile/settings` |
| 详情 | 衣物详情 | `/clothing/[id]` |

## 二、本地预览

```bash
# ⚠️ 必须切换到功能分支，master 上还没有原型代码
git fetch origin
git checkout cursor/ui-interactive-prototype-6952
git pull origin cursor/ui-interactive-prototype-6952

npm install
npm run web
```

浏览器打开终端显示的地址（通常为 `http://localhost:8081`）。

> **注意**：如果你只在 `master` 分支执行 `git pull`，是拉不到这些改动的。当前所有 UI 原型代码都在 `cursor/ui-interactive-prototype-6952` 分支上，对应 PR [#3](https://github.com/WXKFelix/cloudWardrobe-ui/pull/3)。

### 推荐体验路径

1. 欢迎页 → **注册新账号**
2. 填写账号密码 → 注册成功 → **云空间赠送弹窗**
3. 选择用户类型 → 新手引导 → **录入第一件衣物**
4. 返回首页 → 查看 **今日穿搭推荐** → 点击「穿上这套」
5. 浏览 **衣橱 / 记录 / 我的** 各 Tab
6. 或使用 **登录**（预填 demo / demo1234）快速进入主界面
7. **我的** → 逐个体验 5 个子模块（云空间 / 会员 / 订单 / 反馈 / 设置）

### 登录页密码优化（v1.1）

- 密码框右侧提供 **小眼睛图标**（`eye-outline` / `eye-off-outline`）
- 点击可切换显示/隐藏密码，登录页和注册页均支持

### 「我的」子模块交互说明

| 子模块 | 交互能力 |
|--------|----------|
| 云空间管理 | 查看用量与分类占用、选择扩容方案、模拟升级成功 |
| 会员中心 | 查看等级/积分进度、权益列表、积分兑换（200/500 积分） |
| 我的订单 | 按类型筛选、查看订单详情弹窗、取消进行中的订单 |
| 意见反馈 | 选择反馈类型、填写内容、模拟截图、提交成功提示 |
| 设置 | 穿搭/推广/订单通知开关、隐私分享、深色模式（原型模拟） |

## 三、设计规范

|------|-----|

## 四、与 PRD 的对应关系

- 底部 5 Tab 导航：首页 / 衣橱 / 录入(+) / 记录 / 我的
- 注册赠送 50 件云空间
- 用户类型三分法：学生 / 上班族 / 家庭
- 首页天气 + 穿搭推荐 + 打卡
- 衣橱搜索与分类筛选
- 录入支持拍照（模拟）与手动模式
