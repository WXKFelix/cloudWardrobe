## 产品定位（一句话）

**以「数字衣橱 + 异地存取 + 智能穿搭」为核心的衣物生活服务平台**——让用户像点菜一样随性穿衣，把物理衣柜搬到云端，把穿搭决策交给系统。

## 核心价值主张

1. **想穿就穿**：每日 AI 穿搭推荐，告别出门前的选择焦虑
2. **轻装出行**：跨省/跨国异地取还，行李箱不再被衣服占满
3. **衣橱不堆山**：云端管理 + 实体仓储，家里只留当季常穿
4. **衣物有归宿**：捐赠、折旧置换、定期保养，延长衣物生命周期
5. **安全可靠**：云端档案 + 实体仓库存储，衣物资产可追踪、可恢复
