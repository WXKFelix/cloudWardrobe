# 云衣柜 · 品牌视觉与设计系统

**版本**：v1.0  
**设计关键词**：环保 · 高科技 · 随性 · 可持续

---

## 一、品牌愿景

> 让穿衣不再困难，随时随地想穿就穿！  
> 新世纪的穿衣，不再刻板无聊——像吃饭一样随性。  
> 在智能云端管理衣物，用绿色理念延长每一件衣服的生命。

---

## 二、设计原则

| 原则 | 视觉表达 |
|------|----------|
| **环保** | 森林绿主色、叶片语义、循环/捐赠/减量提醒 |
| **高科技** | 极光薄荷点缀、光晕边框、AI 标签、玻璃质感卡片 |
| **随性** | 圆润布局、轻松文案、少步骤交互 |
| **可持续** | 衣物生命周期可视化、绿色提醒、云空间代替物理堆积 |

---

## 四、核心组件

| 组件 | 作用 |
|------|------|
| `EcoBackground` | 页面背景光晕 + 科技线条 |
| `ScreenContainer` | 统一背景容器 |
| `Card`（glow） | 玻璃质感 + 科技边框 |
| `Button`（primary） | 绿色底 + 薄荷光晕 |

---

## 五、文案规范

品牌文案统一维护在 `constants/brand.ts`：

- **Slogan**：让穿衣不再困难 / 随时随地，想穿就穿
- **Mission**：像吃饭一样随性穿衣，告别刻板与浪费
- **Eco Tagline**：智能云端 · 绿色生活
