# 《量化人生》UI 设计规范（MVP）

## 1. 设计目标

- **有的放矢**：主屏突出「主线」与「今日对齐」，避免仪表盘堆砌。
- **岔口清晰**：决策流像向导，结果页像「对比表 + 叙述」，不像聊天。
- **尊重不可量化**：轨迹与决策中保留叙事区块，默认不要求一切打分。

---

## 2. 品牌与气质

| 维度 | 说明 |
|------|------|
| 关键词 | 清醒、温和、可信赖、不贩卖焦虑 |
| 视觉隐喻 | 人生路径：圆点节点 + 连接线；岔口用「路标」图标 |
| 禁止 | 排行榜、人生总分、红绿焦虑式 KPI 闪烁 |

## 4. 字体与层级

- **标题**：28 / 22 / 18，字重 600–700
- **正文**：16，行高 24
- **辅助**：14，行高 20
- **数据**：tabular nums，18–20 半粗

---

## 5. 间距与圆角

- 页面水平 padding：**20**
- 卡片 padding：**16–20**
- 卡片圆角：**16**
- 按钮圆角：**12**
- 区块间距：**12 / 24 / 32**

---

## 6. 核心组件

| 组件 | 说明 |
|------|------|
| `Screen` | SafeArea + 背景色 + 可选 scroll |
| `Card` | 白底、浅阴影、圆角 16 |
| `PrimaryButton` / `SecondaryButton` | 全宽或 inline |
| `SliderField` | 0–10，显示当前值 |
| `StepIndicator` | 向导步骤 1/4 |
| `PathCard` | 决策结果：标题、标签、分项条、摘要 |
| `TimelineNode` | 左侧轴 + 节点圆点 + 阶段卡片 |
| `AlignmentRing` | 简化为半圆进度（MVP：对齐度 0–100） |
| `Sparkline` | 7 日签到折线（轻量自绘） |

## 8. 关键页面线框说明

### 8.1 Onboarding（3 步）

1. **价值观**：三枚 Slider（成长 / 稳定 / 风险），文案解释「用于权衡建议权重」。
2. **主线**：单行输入「当前最想推进的一件事」+ 示例占位。
3. **锚点与当前站**：锚点 A 标签（如「家乡·小城」）+ 当前阶段名（如「在 B·上海」）。

Primary CTA：**开始记录人生**

### 8.2 今日

- 顶部：问候 + 当前阶段 chip
- 中央：`AlignmentRing` + 一句人话（「本周主线投入偏低」规则可后续细化，MVP 用昨日 alignment）
- 「30 秒签到」三 Slider
- 底部：7 日 sparkline

### 8.3 轨迹

- 竖向 timeline，最新在上
- FAB：**添加阶段**
- 空态：虚线 + 「从 A 出发，记录你路过的 B、C…」

### 8.4 决策 · Offer 向导

步骤 1 数字事实 → 步骤 2 时间与成长 → 步骤 3 不可量化（三短句 + 可选长文）→ 步骤 4 确认

### 8.5 决策结果

- 免责声明条（灰底小字）
- 3 张 `PathCard`（并列 scroll）
- 「假设清单」bullet
- 「复盘日：YYYY-MM-DD」+ 保存到日志
- 次要：**导出本次结论**（复制 JSON 摘要）

### 8.6 设置

- 编辑价值观与主线
- **导出全部数据**
- 链接 PRD 原则摘要

---

## 9. 动效（MVP 从简）

- 页面切换：系统默认
- 按钮：opacity 0.85 on press
- 不对齐度做连续动画环（静态弧即可）

---

## 10. 无障碍

- 所有 Slider 带 `accessibilityLabel`
- 对比度：正文与背景 ≥ 4.5:1
- 不单独用颜色传达路径优劣（配合标题与文字）

---

## 11. 资产

- 沿用 `assets/` 中 Expo 默认 icon/splash（MVP）；后续替换为路径/路标主题 icon。
